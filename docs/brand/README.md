# Logo de Recov

Logo oficial confirmado el 22 de octubre de 2026. Todo uso del logo sale de estos archivos.

| Archivo | Qué es |
| --- | --- |
| `recov-logo-original.png` | El archivo entregado (1254 × 1254 px, con margen blanco). No se usa directo. |
| `recov-logo.png` | El logo recortado al cuadrado celeste, con las esquinas transparentes (896 × 896 px). Fuente para cualquier otro tamaño. |

En la app:

| Archivo | Uso |
| --- | --- |
| `src/app/recov-logo.png` | Logo del menú lateral (512 px, esquinas transparentes). |
| `src/app/icon.png` | Ícono de la pestaña del navegador (192 px). |
| `src/app/favicon.ico` | Ícono clásico de la pestaña (48 px). |
| `public/icons/icon-192.png`, `icon-512.png` | Íconos de la Web App instalada (manifest, "any"): el logo con sus esquinas redondeadas, fondo transparente. |
| `public/icons/icon-maskable-512.png` | Ícono "maskable" de Android: celeste a sangre con la R centrada en el 55 % del lado (zona segura). |
| `public/icons/apple-touch-icon.png` | Ícono al guardar la app en la pantalla de inicio del iPhone (180 px, celeste a sangre sin transparencia: iOS redondea las esquinas). |

Celeste del logo: `#0CA9FE`. La "R" y el punto van en blanco.

Para generar otro tamaño, achicar `recov-logo.png` (no el original). Si cambia el logo, reemplazar `recov-logo-original.png` y regenerar todos los tamaños de la tabla.
